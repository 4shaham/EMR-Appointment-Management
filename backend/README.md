# Enterprise EMR Appointment Management System — Backend

Refer to the main [Root README.md](../README.md) for full project documentation, architectural diagrams, API reference, and setup instructions.

### Quick Start:
```bash
# 1. Install dependencies
npm install

# 2. Configure .env
cp .env.example .env

# 3. Seed demo data
npm run seed

# 4. Start development server
npm run dev
```

### Build & Typecheck:
```bash
npm run typecheck
npm run build
npm start
```
